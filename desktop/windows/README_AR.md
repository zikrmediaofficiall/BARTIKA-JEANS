# BARTIKA JEANS — نسخة Windows

## ما الذي يتم تثبيته؟

هذه حزمة سطح مكتب خفيفة تفتح موقع BARTIKA JEANS داخل نافذة برنامج مستقلة، وتضيف اختصارًا إلى سطح المكتب وقائمة Start. لا تشغّل خادم Next.js محليًا ولا تنسخ قاعدة بيانات Supabase إلى اللابتوب؛ واجهة المتجر والإدارة تُحمّل من:

https://bartika-jeans.vercel.app/

## التوافق

- حزمة Windows 7 مبنية على Electron 22.3.27 / Chromium 108، وهو آخر خط Electron يدعم Windows 7.
- ينتج البناء ملف تثبيت واحدًا يدعم Windows 64-bit (x64) و32-bit (ia32)، ويختار NSIS المعمارية المناسبة تلقائيًا.
- يستهدف هذا البناء Windows 7 SP1 مع تحديثات النظام المطلوبة وتشغيل TLS حديث. لا يمكن ضمان عمله على نسخة Windows 7 غير محدثة أو معدلة.
- **تحذير أمني مهم:** Windows 7 انتهى دعمه الأمني من Microsoft في 14 يناير 2020، ودعم Electron 22 انتهى في 10 أكتوبر 2023. Chromium المضمن قديم ولا يتلقى تصحيحات أمنية. هذه الحزمة للتوافق والاختبار فقط، ولا يُنصح باستخدامها مع بيانات العملاء أو المبيعات الحقيقية أو كلمات المرور على جهاز متصل بالإنترنت. الحل الآمن هو ترقية اللابتوب إلى نظام تشغيل ما زال يتلقى تحديثات أمنية، ثم إصدار تطبيق سطح مكتب مبني على Electron حديث.

## إصلاح بدء التشغيل في الإصدار 1.0.0-legacy.2

- يعرض البرنامج شاشة بدء محلية قبل محاولة فتح الموقع؛ لا ينتظر تحميل الإنترنت لإظهار نافذته.
- يعطّل تسريع GPU لأن تعريفات الرسوميات القديمة على بعض أجهزة Windows 7 قد تسبب توقف Chromium عن الرسم.
- عند عدم اكتمال تحميل الموقع خلال 30 ثانية ينتقل إلى صفحة محلية توضح حالة الاتصال.
- يسجل إصدار Electron وChromium ونظام التشغيل وأخطاء التنقل وانهيار renderer في `logs\startup.log` داخل مجلد بيانات التطبيق.

## التثبيت

1. افتح GitHub Releases لمستودع BARTIKA JEANS.
2. نزّل ملف Setup المرفق باسم قريب من `BARTIKA-JEANS-1.0.0-legacy.2-Windows-Setup.exe`.
3. شغّل Setup واتبع خطوات التثبيت. سيظهر اختصار BARTIKA JEANS على سطح المكتب وقائمة Start.
4. يلزم الإنترنت عند أول تشغيل لتسجيل الدخول وتحميل الموقع.

## حدود الاتصال والعمل دون إنترنت

هذا البرنامج غلاف سطح مكتب للموقع المنشور، وليس نسخة كاملة مستقلة Offline. يظل دعم العمل دون اتصال محدودًا إلى إمكانات POS الحالية (الكتالوج الذي تم تحميله مسبقًا وطابور المبيعات المحلي). بقية صفحات الإدارة تحتاج الإنترنت، وتظل المبيعات غير المتصلة معلّقة حتى يتحقق منها الخادم عند المزامنة. بيانات المتصفح المخزنة محليًا قد تُحذف عند إلغاء تثبيت البرنامج أو مسح بياناته.

## بناء الحزمة

من هذا المجلد:

```powershell
npm install
npm run dist:win
```

ينتج Electron Builder ملف Setup واحدًا يدعم x64 وia32 داخل `dist/`.
