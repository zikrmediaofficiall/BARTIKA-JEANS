# BARTIKA JEANS — دليل حل مشكلة بدء التشغيل

## التغييرات في الإصدار 1.0.0-legacy.2

1. تظهر شاشة بدء محلية فور فتح البرنامج، بدل انتظار تحميل الموقع قبل إظهار النافذة.
2. تعطيل تسريع الرسوميات GPU في حزمة Windows 7 لتجنب تعليق/انهيار تعريفات الرسوميات القديمة.
3. إضافة مهلة 30 ثانية لتحميل الموقع؛ عند فشل الاتصال تظهر صفحة محلية بدل نافذة مخفية أو فارغة.
4. تسجيل أخطاء بدء التشغيل وفشل تحميل الصفحة وانهيار renderer والعمليات الفرعية.
5. إضافة معلومات إصدار Electron وChromium ونظام التشغيل إلى سجل التشخيص.

## مكان سجل التشخيص

من مستكشف الملفات افتح `%APPDATA%`، ثم مجلد بيانات BARTIKA JEANS، ثم:

`logs\startup.log`

قد يختلف اسم مجلد بيانات التطبيق بحسب اسم المنتج الذي سجله Windows. أرسل ملف `startup.log` كاملًا عند تكرار المشكلة، مع الاحتفاظ بأي رسائل خطأ ظاهرة على الشاشة.

## إذا استمر البرنامج في عدم الفتح

- احذف النسخة السابقة من لوحة Control Panel > Programs and Features.
- لا تحذف مجلد بيانات المستخدم إذا كان يحتوي على مبيعات Offline لم تتم مزامنتها.
- أعد تشغيل Windows ثم ثبّت ملف Setup الجديد.
- تأكد من Windows 7 Service Pack 1 والتحديثات الأمنية اللازمة لـTLS/شهادات الجذر.
- ثبّت Microsoft Visual C++ Redistributable 2015–2022 المناسب لمعمارية النظام عند ظهور رسالة DLL مفقود.
- جرّب فتح الموقع نفسه من متصفح حديث مدعوم على جهاز آخر للمقارنة.

## حدود التحقق

بناء GitHub Actions يتحقق من تجميع ملفات x64 وia32 وصحة تركيب حزمة Windows؛ لا يستطيع إثبات توافق تعريفات جهازك أو Windows 7 المثبت عليه. يلزم اختبار الجهاز الفعلي وقراءة `startup.log` لتأكيد السبب النهائي إذا استمر التعليق.

## تحذير أمني

Electron 22 / Chromium 108 متوقفان عن تلقي تحديثات الأمان، وWindows 7 انتهى دعمه الأمني. هذه حزمة توافق وتجربة فقط، ولا تستخدمها لإدخال كلمات مرور أو بيانات عملاء أو تنفيذ مبيعات حقيقية على جهاز متصل بالإنترنت. الأفضل ترقية Windows إلى إصدار مدعوم ثم إصدار حزمة Electron حديثة.
