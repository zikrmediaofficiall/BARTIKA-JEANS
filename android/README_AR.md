# تطبيق BARTIKA JEANS لأندرويد

## طريقة التشغيل

التطبيق الأصلي يفتح النظام المنشور عبر HTTPS داخل Android WebView. عند الاتصال يستخدم النظام الكامل على الخادم. يخزن WebView ملفات Service Worker وبيانات IndexedDB في مساحة التطبيق الخاصة على الجهاز، ولا يشاركها تلقائيًا مع متصفح Chrome أو جهاز آخر.

## العمل دون اتصال — النطاق الحالي

- افتح التطبيق بالإنترنت وسجّل الدخول بحساب له صلاحية البيع.
- افتح نقطة البيع /pos مرة واحدة حتى يُحفظ آخر كتالوج متاح وحد الخصم في IndexedDB.
- بعد ذلك يمكن فتح /offline-pos.html دون اتصال، وإضافة عمليات بيع إلى قائمة محلية معلّقة.
- عند عودة الاتصال يحاول التطبيق مزامنة العمليات المعلّقة تلقائيًا. الخادم يعيد التحقق من هوية المستخدم ودوره والخصم والمخزون والوردية ومفتاح منع التكرار.
- أي عملية لا تجتاز التحقق تبقى بحالة «تحتاج مراجعة» ولا تُعتبر فاتورة معتمدة.
- المزامنة إلى قاعدة البيانات المركزية تتطلب اتصالًا فعليًا بالإنترنت وجلسة دخول صالحة.

## حدود مهمة

هذا إصدار Offline POS وليس نسخة محلية كاملة لكل وحدات الإدارة. الصفحات الأخرى (المخزون والإعدادات والموردون والتقارير والعملاء وإدارة الموظفين والطلبات العامة) تحتاج الاتصال بالخادم. كتالوج Offline هو آخر نسخة تم تحميلها من نقطة البيع، وليس مخزونًا لحظيًا عالميًا.

البيانات المحلية محفوظة في مساحة WebView الخاصة بالتطبيق على أندرويد، وفي IndexedDB داخل ملف المستخدم للمتصفح على اللابتوب. حذف بيانات التطبيق أو إلغاء تثبيته أو مسح بيانات الموقع من المتصفح قد يحذف هذه البيانات. طلب التخزين الدائم Best Effort وليس ضمانًا ضد حذف المستخدم أو النظام للبيانات.

عمليات البيع Offline لا تخصم المخزون المركزي ولا تصدر فاتورة نهائية قبل التحقق من المزامنة. لا تعتمد على مخزون الجهاز المنفصل باعتباره رصيدًا لحظيًا على كل الأجهزة.

- JDK: 17

- Application ID: com.bartika.jeans

مخرجات GitHub Actions الحالية مخصصة للاختبار وموقّعة بمفتاح Debug:
- APK قابل للتثبيت للاختبار.
- AAB تشخيصي موقّع بمفتاح Debug، وليس ملف رفع إنتاجي إلى Google Play.

لإصدار Google Play إنتاجي، يجب استخدام مفتاح رفع خاص ومستمر محفوظ في GitHub Actions Secrets (ANDROID_KEYSTORE_BASE64, ANDROID_KEYSTORE_PASSWORD, ANDROID_KEY_ALIAS, ANDROID_KEY_PASSWORD) وعدم نشره أو إرفاقه بالمستودع أو الـRelease.
